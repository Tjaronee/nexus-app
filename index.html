Nexus

Hoe maak ik een token?
  1. Open een nieuw fine-grained token op GitHub.
  2. Kies bij Repository access: Only select repositories → Tjaronee/Nexus.
  3. Zet bij Permissions → Issues op Read and write. Verder niets.
  4. Maak het token aan, kopieer het en plak het hierboven.

Je token blijft alleen op dit apparaat bewaard.
